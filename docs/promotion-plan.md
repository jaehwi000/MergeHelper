# MergeHelper 홍보 자동화 방안

- 작성일: 2026-10-16
- 대상 서비스: https://jaehwi000.github.io/MergeHelper/
- 대상 사용자: 2~4개 마켓에서 판매하는 월 주문 100~1,000건 규모의 소규모 셀러

## 기본 원칙

1. **사람이 검색하는 순간에 걸리게 만든다.** 셀러는 불편할 때 "주문 엑셀 합치기", "합포장 엑셀" 같은 말로 검색합니다. 검색 노출은 한 번 만들어 두면 계속 사람을 데려옵니다.
2. **커뮤니티 글을 자동으로 올리지 않는다.** 네이버 카페·아이보스 같은 셀러 커뮤니티에 자동으로 글이나 댓글을 올리면 광고·도배로 신고되어 계정이 정지되고, 도구의 평판도 망가집니다. 자동화는 **"찾기와 초안 쓰기"까지만** 하고, 올리는 것은 사람이 합니다.
3. **"데이터가 밖으로 나가지 않는다"는 약속을 지킨다.** 방문자 분석 도구를 붙이면 이 약속과 부딪히므로 신중하게 고릅니다(5절).

## 0단계: 홍보 전에 끝낼 것 (필수)

첫 방문자가 실패를 겪으면 다시 오지 않고, 나쁜 입소문이 납니다.

| 할 일 | 이유 | 누가 |
|---|---|---|
| 스마트스토어·쿠팡 **실제 주문 파일**로 자동 인식 확인 | 지금 열 이름은 추정값이라, 틀리면 첫 화면부터 "열 연결 필요"가 뜸 | 사용자가 샘플 제공 → Claude 수정 |
| SheetJS를 0.20.3 이상으로 교체 | 알려진 취약점이 있는 라이브러리로 공개 홍보하면 안 됨 | 사용자가 파일 제공 → Claude 교체 |
| 의견 받을 창구(구글 폼 링크) | 초기 사용자의 오류 제보가 가장 중요한 개선 재료 | 사용자가 폼 생성 → Claude가 화면에 링크 추가 |
| 실제 셀러 2~3명에게 먼저 써 보게 하기 | 홍보 문구에 쓸 실제 후기·수치(예: "하루 20분 → 2분") 확보 | 사용자 |

## 1단계: 검색에 걸리는 기반 만들기 (한 번 작업, 이후 자동)

| 항목 | 내용 | 자동화 |
|---|---|---|
| 페이지 정보 | 검색 결과·카톡 공유 미리보기에 나오는 제목, 설명, 대표 이미지(meta, Open Graph) | 코드에 한 번 넣으면 끝 |
| 사용 사례 안내 페이지 5~10개 | 검색어 하나당 한 페이지: "스마트스토어 쿠팡 주문 엑셀 합치기", "합포장 묶음배송 엑셀로 찾기", "송장번호 일괄 등록 엑셀 만들기", "EUC-KR CSV 글자 깨짐", "피킹 리스트 만들기" 등. 각 페이지는 해결 방법 설명 + 도구 링크 | 템플릿 하나로 생성. 새 기능이 생기면 페이지 추가 |
| 사이트맵, robots.txt | 검색엔진이 페이지를 빨리 찾게 함 | GitHub Actions 배포 때 자동 생성 |
| 검색엔진 등록 | **네이버 서치어드바이저**와 **구글 서치 콘솔**에 사이트 등록, 사이트맵 제출 | 처음 한 번만 사용자가 직접(소유 확인 필요) |
| 도구 소개 사이트 등록 | 디스콰이엇 등 메이커 커뮤니티의 제품 소개란, GitHub 저장소 소개·주제(topics) | 한 번만 수동 |

국내 셀러는 네이버 검색 비중이 커서 네이버 서치어드바이저 등록이 특히 중요합니다.

## 2단계: 매일 "도움이 필요한 글" 찾아 답변 초안 받기 (반자동)

가장 효과가 큰 홍보는 **지금 바로 그 문제로 질문한 사람에게 도움이 되는 답을 다는 것**입니다.

```
[매일 아침 예약 작업(Claude)]
  1. 최근 24~48시간 사이 새로 올라온 질문 검색
     예: "주문 엑셀 합치기", "스마트스토어 쿠팡 송장", "합포장 엑셀", "주문서 취합"
     대상: 네이버 지식iN, 아하, 아이보스 Q&A, 블로그·카페 공개 글(검색으로 보이는 것)
  2. 관련도 높은 글 3~5개 고르기(광고 글, 이미 해결된 글 제외)
  3. 글마다 답변 초안 작성
     - 먼저 엑셀만으로 해결하는 방법을 성실히 설명
     - 마지막에 "이런 무료 도구도 있다"는 한 줄 + 링크 (도구 제작자임을 밝힘)
  4. Gmail로 요약 메일 발송: 글 링크 + 초안
[사람]
  메일을 보고 괜찮은 것만 직접 다듬어서 올림 (하루 5~10분)
```

- 이 세션에 연결된 **Gmail**과 Claude **예약 작업**으로 만들 수 있습니다. 서버나 비용이 들지 않습니다.
- 커뮤니티마다 홍보 규칙이 다르므로, 링크를 금지하는 곳에서는 링크 없이 방법만 답합니다.
- 제작자임을 밝히는 것은 꼭 지킵니다(숨긴 홍보는 신뢰를 잃고 규정 위반이 될 수 있음).

## 3단계: 새 기능을 낼 때 홍보 글 초안 자동 생성

```
[GitHub에 새 버전(Release) 등록]
  → 예약 작업 또는 GitHub Actions가 바뀐 내용(커밋·릴리스 노트)을 읽음
  → 채널별 초안 생성: 블로그 글(검색용 긴 글), 스레드/X(짧은 글), 카페 공지형
  → 저장소 docs/drafts/ 에 저장하거나 메일로 받음
[사람] 확인 후 직접 게시
```

- 블로그 글은 1단계 사용 사례 페이지와 연결되어 검색 노출을 함께 키웁니다.
- 게시까지 자동으로 하려면 각 서비스의 API 키가 필요하고 플랫폼 정책 확인이 필요합니다. 초기에는 초안까지만 권합니다.

## 4단계: 도구 안에서 자연스럽게 퍼지게 하기

| 방법 | 내용 |
|---|---|
| 작업 완료 후 안내 | 내려받기가 끝나면 "도움이 됐다면 동료 셀러에게 공유해 주세요" 문구와 링크 복사 버튼 |
| 의견 보내기 | 오류·요청 제보 링크(구글 폼). 제보한 사람에게 반영 소식을 알리면 재방문과 추천으로 이어짐 |
| 하지 않을 것 | 내려받는 엑셀 파일 안에 홍보 문구 넣기. 택배사·마켓 업로드 양식을 깨뜨릴 수 있음 |

## 5단계: 효과 측정

| 방법 | 장단점 |
|---|---|
| 네이버 서치어드바이저·구글 서치 콘솔 | 검색 노출 수, 클릭 수, 어떤 검색어로 들어왔는지. 사이트에 코드를 넣지 않아 약속과 충돌 없음 → **우선 권장** |
| 쿠키 없는 방문자 수 집계(예: GoatCounter) | 방문 수만 셈. 하지만 외부로 연결이 생기므로 보안 정책(CSP) 수정과 안내 문구 변경이 필요 → 사용자 판단 필요 |
| 2단계 메일에 기록 | 답을 단 글의 수, 그 뒤 검색 유입 변화 |

## 추천 순서

1. **0단계** 완료(실제 파일 확인, SheetJS 교체, 의견 창구) — 1~2일
2. **1단계** 페이지 정보 + 사용 사례 페이지 + 사이트맵 → 서치어드바이저·서치 콘솔 등록 — 1일
3. **2단계** 매일 질문 찾기 + 답변 초안 메일 예약 작업 설정 — 30분
4. 2주 뒤 서치 콘솔 수치와 받은 의견을 보고 3·4단계 진행 여부 결정

## Claude가 바로 할 수 있는 것

- 1단계 코드 작업 전체(페이지 정보, 사용 사례 페이지, 사이트맵·robots 자동 생성)
- 4단계 공유 버튼·의견 링크 추가(폼 주소만 주시면)
- 2단계 예약 작업 만들기(Gmail로 매일 요약 메일)
- 3단계 릴리스 기반 홍보 초안 생성

## 사용자가 직접 해야 하는 것

- 실제 주문 파일 샘플, SheetJS 0.20.3 파일, 구글 폼 생성
- 네이버 서치어드바이저·구글 서치 콘솔 가입과 소유 확인
- 커뮤니티 답변 게시(사람이 확인하고 올리기)
